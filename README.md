## Running Locally

```
pip install -r requirements.txt
python hello.py
```

## Containerization

Build the Docker image:

```
docker build -t hello-flask-app .
```

Run the container:

```
docker run -p 5000:5000 hello-flask-app
```

## Publishing to Cloud (Example: Docker Hub)

1. [Create a Docker Hub account](https://hub.docker.com/).
2. Login to Docker Hub:
   ```
   docker login
   ```
3. Tag your image:
   ```
   docker tag hello-flask-app <your-dockerhub-username>/hello-flask-app:latest
   ```
4. Push to Docker Hub:
   ```
   docker push <your-dockerhub-username>/hello-flask-app:latest
   ```

## Deploying to a Cloud Provider (Example: AWS Elastic Beanstalk)

1. Install the [AWS CLI](https://docs.aws.amazon.com/cli/latest/userguide/getting-started-install.html) and [EB CLI](https://docs.aws.amazon.com/elasticbeanstalk/latest/dg/eb-cli3-install.html).
2. Initialize your EB app:
   ```
   eb init -p docker hello-flask-app
   ```
3. Create an environment and deploy:
   ```
   eb create hello-flask-env
   eb open
   ```

---

- The Flask app is configured to run on `0.0.0.0:5000` for Docker/cloud compatibility.
- The `.dockerignore` file excludes sensitive and unnecessary files from the image.
- Update requirements.txt if you add more dependencies.
